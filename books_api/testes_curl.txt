Operações Obrigatórias (Casos de Sucesso)
1. Listar todos os livros
curl.exe -i -X GET http://localhost:8000/api/books

2. Consultar livro existente
curl.exe -i -X GET http://localhost:8000/api/books/1

3. Criar novo livro
curl.exe -i -X POST http://localhost:8000/api/books -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"Grande Sertao: Veredas\", \"author\": \"Guimaraes Rosa\", \"year\": 1956, \"available\": true}'

4. Atualizar livro existente
curl.exe -i -X PUT http://localhost:8000/api/books/1 -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"Dom Casmurro\", \"author\": \"Machado de Assis\", \"year\": 1899, \"available\": false}'

5. Remover livro existente
curl.exe -i -X DELETE http://localhost:8000/api/books/2

Casos de Erro
6. Consultar livro inexistente (404)
curl.exe -i -X GET http://localhost:8000/api/books/999

7. Consultar livro com identificador inválido (400)
curl.exe -i -X GET http://localhost:8000/api/books/abc

8. Criar livro com JSON malformado (400)
curl.exe -i -X POST http://localhost:8000/api/books -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"Livro quebrado\",'

9. Criar livro com campo obrigatório ausente (400)
curl.exe -i -X POST http://localhost:8000/api/books -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"Sem autor\", \"year\": 2020, \"available\": true}'

10. Criar livro com tipo de dado incompatível (400)
curl.exe -i -X POST http://localhost:8000/api/books -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"Ano errado\", \"author\": \"Author X\", \"year\": \"mil novecentos\", \"available\": true}'

11. Atualizar livro inexistente (404)
curl.exe -i -X PUT http://localhost:8000/api/books/999 -H "Content-Type: application/json; charset=utf-8" -d '{\"title\": \"X\", \"author\": \"Y\", \"year\": 2000, \"available\": true}'

12. Remover livro inexistente (404)
curl.exe -i -X DELETE http://localhost:8000/api/books/999

13. Acessar rota inexistente (404)
curl.exe -i -X DELETE http://localhost:8000/api/rota/inexistente
